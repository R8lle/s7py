# TIA Portal — Put/Get und OPC UA für s7py

In der App: *Hilfe → TIA Portal (Put/Get & OPC UA)* (inkl. PDF-Export).

Hier im Repository: separate Kurz-Anleitungen nach **TIA-Version**.

## Was sich ändert

- **V16–V18** — Put/Get unter *Schutz*; OPC-UA-Benutzer in den CPU-Eigenschaften
- **V19** — Lokale Benutzerverwaltung (UMAC); Put/Get oft erst nach Rollen frei
- **V20–V21** — Wie V19; ab FW V4.0 zusätzlich OPC-UA-Namensraum-Rechte (Browse/Read)

Die **projektierte CPU-Firmware** zählt mit: neues TIA + alte FW → eher die ältere Anleitung.
